## After each change

- When there is something which needs to be discussed with the user, create a file in `messages` folder
    - If you dont know or are unsure about something, write me a message.
    - Writing a message instead of making destructive actions is preferred.
- Do a proper analysis of the current functionality before you start implementing.
- Write all the changes to the `CHANGELOG.md`.
- Update the `README.md` if necessary.
- Update the `AGENTS.md` if necessary.
- If you can finish current tasks, create a spec for it but do not implement it immediately
    - Specs are in folder `prompts`
    - One spec is per one file
    - When you are creating new spec, it should have `[-]` at the first line of the file
