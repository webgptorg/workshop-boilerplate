# Společný stůl

Jídelníček školní jídelny pro žáky, rodiče a kuchyni. První verze bez databáze, data jsou uložená v local storage prohlížeče.

## Spuštění

```bash
npm install
npm run dev
```

## Zkušební účty

| Role    | Uživatelské jméno | Heslo        |
| ------- | ----------------- | ------------ |
| Žák     | `zak`             | `zak123`     |
| Jídelna | `jidelna`         | `jidelna123` |
| Rodič   | `rodic`           | `rodic123`   |

## Kontroly

```bash
npm run check
```

Spustí lint, kontrolu typů a build.
